System architecture

How PayPilot moves money safely

PayPal events become incidents, an agent gathers evidence, and a deterministic policy gate decides whether a refund executes automatically, waits for a human, or is blocked. Every step is written to a hash-chained audit ledger.

Refund incident workflow

sandbox · idempotent · hash-chained
01

Deterministic gate

policy.py is plain Python with no model call. The same facts always produce the same allow, review, or deny verdict.

02

Evidence required

Every proposal cites evidence IDs. A proposal with no evidence is denied before any money can move.

03

Idempotent by design

Incident creation is idempotent per payment, and an executed action cannot execute twice.

04

Auditable outcome

Every step appends a SHA-256 hash-chained ledger entry. /api/ledger/verify recomputes the chain.
