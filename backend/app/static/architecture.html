System architecture

AI-assisted planning, deterministic control

PayPilot separates AI-generated planning from deterministic policy enforcement. When configured, Gemini 3.1 Flash Lite proposes a structured next step; the tool registry, policy gate, and approval rules decide what can actually execute. Money-moving actions run only through policy-approved paths (with human approval where required) against PayPal Sandbox/mock adapters.

Incident handling workflow

Gemini planner · structured plan · policy gate · approvals
01

Separated responsibilities

AI-generated planning (Gemini Planner → Structured Plan) is distinct from deterministic policy enforcement (Policy Gate). The planner suggests; policy and code decide.

02

Deterministic gate

policy.py is plain Python with no model call. The same facts produce the same allow, review, or deny verdict and gate execution accordingly.

03

Human control where required

Review-gated actions require explicit human approval. Denied actions are blocked. The planner cannot bypass the tool registry, policy gate, or approval requirements.

04

Auditable outcomes

Evidence, proposals, verdicts, approvals, and execution results are recorded in a hash-chained audit ledger. /api/ledger/verify recomputes the chain.
